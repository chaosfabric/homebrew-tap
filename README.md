# chaosfabric Homebrew tap

Homebrew formulae for tools maintained under the
[chaosfabric](https://github.com/chaosfabric) umbrella.

## Install

```sh
brew install chaosfabric/tap/<formula>
For example, brainyz:

brew install chaosfabric/tap/brainyz
```

## Formulae

|Formula|Project|Platforms|
|-------|-------|---------|
|brainyz|FavitoX/brainyz|macOS arm64, Linux x64, Linux arm64|

## Updates
Formulae in this tap are pushed automatically by each project's release workflow on stable tags. See the upstream repo for release cadence.
